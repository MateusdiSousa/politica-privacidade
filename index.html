1. Dados Coletados

Ao preencher nossos formulários de interesse em imóveis na planta, via Meta (Facebook/Instagram), coletamos os seguintes dados fornecidos voluntariamente:

  • Nome completo
  • Telefone / WhatsApp
  • Faixa de renda mensal

2. Como os Dados são Processados

Os dados são recebidos pela API de Lead Generation da Meta e tratados exclusivamente por mim para fins de contato comercial. Não vendemos, alugamos ou compartilhamos seus dados com terceiros.

3. Finalidade do Tratamento

Os dados são utilizados para:

  • Entrar em contato (ligação, WhatsApp ou mensagem) para apresentar oportunidades de imóveis na planta compatíveis com o seu perfil;
  • Realizar follow-up sobre o interesse manifestado;
  • Cumprir obrigações legais.

O tratamento é baseado no consentimento do usuário (ao submeter o formulário).

4. Retenção e Exclusão de Dados

Os dados são mantidos enquanto houver interesse ativo na negociação. Para solicitar a exclusão dos seus dados, basta responder qualquer mensagem com "quero ser removido" ou enviar um e-mail para mateus.sousa.ra@gmail.com. Respondemos em até 15 dias úteis.

5. Direitos do Usuário (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode a qualquer momento:

  • Confirmar a existência de tratamento;
  • Acessar seus dados;
  • Corrigir dados incompletos ou desatualizados;
  • Solicitar a eliminação;
  • Revogar o consentimento.

Para exercer qualquer direito, entre em contato pelo e-mail: mateus.sousa.ra@gmail.com ou pelo WhatsApp +55 (11) 94744-9899.

6. Compartilhamento com a Meta

Informamos que a Meta Platforms Ireland Ltd. também atua como controladora dos dados coletados por meio de seus formulários instantâneos, nos termos de sua própria Política de Dados.
